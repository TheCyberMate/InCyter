InCyter — Cyber Threat Investigation Platform
=================================================

InCyter is a Windows-based threat investigation desktop app built for security analysts and SOC teams. It consolidates the most common DFIR and CTI workflows into a single dark-themed interface — no switching between browser tabs or tools.

What it does:

Scan IPs, domains, URLs, and file hashes across VirusTotal, AlienVault OTX, AbuseIPDB, Shodan, MalwareBazaar, urlscan.io, and more — all from one place. 
Investigate CVEs with CVSS scores, EPSS ratings, and CISA KEV flags. 
Analyse emails for phishing patterns and BEC indicators. 
Inspect PE files, run YARA rules, extract strings, and compare fuzzy hashes for malware analysis. 
Parse PCAPs for IOCs, beaconing, and lateral movement. 
Extract and defang IOCs from any raw text, bulk scan them, and convert them directly to Sigma detection rules. 
Generate TLP-marked HTML reports with a single click.

Key highlights:

15+ integrated threat intel sources (free and API-based)
Full malware analysis suite: PE Inspector, YARA, ssdeep/TLSH, Strings
Email header + body phishing analysis with BEC detection
MITRE ATT&CK browser and threat actor attribution
IOC extraction, defanging, bulk scanning, and Sigma rule generation
Image OCR for extracting IOCs from screenshots
PCAP analysis with beaconing and lateral movement detection
Exportable HTML reports with TLP classification
Clipboard monitor, scan history, and fully customisable workspace
