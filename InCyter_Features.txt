================================================================================
  InCyter — Cyber Threat Investigation Platform
  Feature Reference
================================================================================

InCyter is a desktop application built for SOC analysts, incident responders,
and security professionals. It consolidates threat intelligence lookups, OSINT
queries, malware analysis, and domain investigation into a single fast interface.

================================================================================
  1. FILE & HASH
================================================================================

  Hash Scanning
    - Paste or type MD5, SHA1, SHA256, or SHA512 hashes
    - Drag and drop any file for automatic hash computation
    - Queries VirusTotal (70+ AV engine results)
    - Queries AlienVault OTX for community threat intelligence
    - Queries filescan.io for static & dynamic sandbox analysis
    - Queries MalwareBazaar (abuse.ch) for known malware samples
    - Queries URLhaus for malicious payload associations

  Inline Find Adversary Panel
    - Search actor/threat group names from within the File & Hash tab
    - Matches against MISP Galaxy clusters and OTX pulse data
    - Displays actor profiles, aliases, target sectors, and references
    - Shows ATT&CK TTP badges inferred from matched actor names

  Inline YARA Scan Panel
    - Run YARA rules against any loaded file from within the tab
    - Displays matched rule names, rule file source, and match offset
    - Infers ATT&CK TTP badges from YARA rule name keywords
      (e.g. "ransomware" → T1486, T1490, T1489)


================================================================================
  2. IP
================================================================================

  - VirusTotal reputation (detection count, community votes, categories)
  - AlienVault OTX community pulses and related IOCs
  - AbuseIPDB confidence score with abuse category breakdown
  - Shodan open ports, services, banners, and associated CVEs
  - ipinfo.io geolocation, ASN, organisation, and hosting data
  - GreyNoise classification (internet background noise vs. targeted)
  - ANY.RUN sandbox submission for IP-based threat analysis


================================================================================
  3. DOMAIN
================================================================================

  - VirusTotal reputation and category classification
  - AlienVault OTX community pulses
  - urlscan.io browser sandbox with screenshot and DOM/DNS analysis
  - ScamAdviser trust score and fraud risk indicators
  - ANY.RUN sandbox submission
  - WHOIS registration data lookup


================================================================================
  4. URL
================================================================================

  - VirusTotal reputation scan
  - AlienVault OTX community lookup
  - urlscan.io browser sandbox (screenshot, verdict, network graph)
  - filescan.io static and dynamic analysis
  - ANY.RUN sandbox submission
  - Safe redirect chain tracing (up to 20 hops with status codes)
  - SSL error detection and final landing page validation


================================================================================
  5. CVE / SOFTWARE
================================================================================

  Sub-tab: CVE Lookup
    - Full CVE detail lookup against NIST NVD
    - CVSS v2 and v3 scores with severity badges (Critical/High/Medium/Low)
    - EPSS score (Exploit Prediction Scoring System percentile)
    - CISA KEV flag — indicates active exploitation in the wild
    - Affected products and vendor/CPE enumeration
    - Published and last-modified timestamps
    - External reference links (advisories, patches, PoC exploits)
    - CWE → MITRE ATT&CK technique inference with clickable badges
    - ATT&CK Browser button on each mapped technique

  Sub-tab: Software Search
    - Search any product name (e.g. openssl, log4j, Google Chrome)
    - Optional version filter to narrow results
    - Returns all known CVEs sorted by CVSS score (highest first)
    - Affected version ranges parsed from CPE configuration data
    - CISA KEV "Actively Exploited" flag highlighted per CVE
    - Click any CVE ID to jump directly to the CVE Lookup tab


================================================================================
  6. TOOLKIT
================================================================================

  Sub-tab: Adversary Intel
    - Search threat actor names, groups, or malware families
    - Matches against MISP Galaxy clusters (actors, intrusion sets,
      ransomware families, malware families)
    - Matches against AlienVault OTX pulse adversary data
    - Displays actor descriptions, aliases/synonyms, target sectors,
      country of origin, and reference links
    - ATT&CK TTP badges shown for 48+ known threat groups
      (e.g. APT29, Lazarus, LockBit, FIN7, Volt Typhoon, Sandworm)
    - Clicking any badge navigates to the in-app ATT&CK Browser

  Sub-tab: Bulk Scan
    - Paste up to 100 IOCs (mixed types supported)
    - Auto-detects IOC type per line (IP, Domain, URL, MD5, SHA256, etc.)
    - Scans each IOC against VirusTotal
    - Per-IOC verdict display: Malicious / Suspicious / Clean / Unknown
    - Detection count shown per result
    - Per-IOC action buttons (view report, copy, remove)
    - Progress indicator and cancel support

  Sub-tab: IOC Extract & Defang
    - Paste any freeform text (email, report, article)
    - Automatically extracts: IPs, domains, URLs, MD5, SHA1, SHA256,
      SHA512 hashes, CVE IDs, and email addresses
    - Filter extracted results by IOC type
    - One-click defang output (hxxp, [.], [@] notation)
    - One-click refang (restore original format)
    - Copy results to clipboard
    - Route any extracted IOC directly to its scanner tab

  Sub-tab: MITRE ATT&CK Browser
    - Full in-app MITRE ATT&CK technique database
    - Search by technique ID (e.g. T1566) or keyword
    - Displays technique name, tactic, description, and sub-techniques
    - CWE-to-technique mapping (318+ techniques indexed)
    - Navigated automatically when clicking ATT&CK badges anywhere in the app


================================================================================
  7. MALWARE ANALYSIS
================================================================================

  Sub-tab: PE Inspector
    - Full PE (Portable Executable) file analysis without external APIs
    - DOS header, File header, Optional header fields
    - Machine type, subsystem, entry point, image base, timestamp
    - Section table: name, virtual size, raw size, entropy per section
    - Import directory: DLL names and imported function enumeration
    - Export directory: exported function names and ordinals
    - Debug information parsing
    - Certificate / digital signature extraction
    - High-entropy section flagging (potential packing/encryption)

  Sub-tab: YARA Scanner
    - Load and manage YARA rule files (.yar / .yara)
    - Download curated public rule sets from within the app
    - Compile and scan files against loaded rules
    - Results show matched rule name, rule file, and match details
    - ATT&CK TTP badges inferred from rule name keywords:
        ransomware, infostealer, stealer, keylogger, spyware, rootkit,
        banker, backdoor, RAT, loader, dropper, downloader, coinminer,
        miner, worm, exploit, trojan, cobalt, meterpreter, and more

  Sub-tab: Fuzzy Hash
    - SSDEEP fuzzy hashing via ppdeep (0–100% similarity scoring)
    - TLSH (Trend Micro Locality Sensitive Hash) pure-Python implementation
    - Compare two files or two hash strings
    - Distance score and similarity percentage display
    - Identify near-duplicate or slightly modified malware samples


================================================================================
  8. EMAIL ANALYSER
================================================================================

  Sub-tab: Email Header
    - Paste raw email source (.eml) or drag and drop .eml / .msg files
    - Parses From, Reply-To, Return-Path, Message-ID, Subject, Date
    - Received chain analysis with hop-by-hop IP extraction
    - Originating IP identification and direct VirusTotal scan button
    - SPF record validation (pass / fail / softfail / neutral / permerror)
    - DKIM signature verification (pass / fail / missing)
    - DMARC policy check (none / quarantine / reject)
    - Authentication-Results header parsing
    - Spoofing and header anomaly indicators

  Sub-tab: Email Body
    - IOC extraction from email body text (IPs, domains, URLs, hashes)
    - Quick-scan button per extracted IOC (routes to correct scanner)
    - Suspicious pattern matching:
        - Phishing redirect patterns
        - Credential harvesting keywords
        - Fake urgency language
        - Gift card / wire transfer social engineering
        - Attachment-based lure detection
    - IOC count summary with type breakdown


================================================================================
  9. DOMAIN TOOLS
================================================================================

  Sub-tab: WHOIS
    - RDAP/WHOIS lookup via ipwhois.app
    - Registrar, registration date, expiry date, name servers
    - Registrant organisation details (where available)
    - Privacy protection detection

  Sub-tab: SSL Cert
    - Certificate Transparency log search via crt.sh
    - Lists all known certificates for a domain (including subdomains)
    - Certificate issuer, validity period, serial number
    - Identifies expired or recently issued certificates

  Sub-tab: Passive DNS
    - Historical DNS resolution records via HackerTarget API
    - IP addresses the domain has resolved to over time
    - Useful for tracking infrastructure reuse across campaigns

  Sub-tab: DMARC
    - Live DMARC TXT record lookup (direct DNS to Cloudflare 1.1.1.1)
    - Policy parsing: none / quarantine / reject
    - Subdomain policy (sp) display
    - SPF alignment mode (aspf) and DKIM alignment mode (adkim)
    - Reporting addresses (rua / ruf) display
    - Remediation guidance:
        - Migration path recommendation (none → quarantine → reject)
        - Missing record detection with setup instructions
        - Partial configuration warnings


================================================================================
  10. SETTINGS
================================================================================

  API Keys
    - Store and manage keys for:
        VirusTotal, Shodan, ANY.RUN, urlscan.io,
        OTX (AlienVault), AbuseIPDB
    - Show / hide key toggle per field
    - Test button per API to validate key instantly
    - Keys saved locally in ioc_scanner_config.json

  Features
    - Toggle optional integrations on or off:
        VirusTotal, ANY.RUN, AbuseIPDB
    - Clipboard IOC auto-detection toggle
    - Defang / refang output format preferences

  Feature Selection
    - Show or hide any top-level tab from the sidebar
    - Show or hide individual sub-tabs within each section:
        CVE / Software:   CVE Lookup, Software Search
        Toolkit:          Adversary Intel, Bulk Scan,
                          IOC Extract & Defang, MITRE ATT&CK
        Malware Analysis: PE Inspector, YARA Scanner, Fuzzy Hash
        Email Analyser:   Email Header, Email Body
        Domain Tools:     WHOIS, SSL Cert, Passive DNS, DMARC
    - Changes apply instantly; preferences persist across restarts
    - Home and Settings tabs are always visible

  History
    - IOC Scanner history: timestamp, IOC value, type, analyst verdict
    - Tools history: WHOIS, SSL Cert, Passive DNS, DMARC, CVE Lookup,
      MalwareBazaar, URLhaus, GreyNoise, Software Search queries
    - Analyst notes — add custom notes to any history entry
    - Verdict cycling per IOC (Unknown → Malicious → Clean)
    - Search and filter within history
    - Export history to CSV

  About
    - App version, author, and platform details


================================================================================
  GENERAL FEATURES
================================================================================

  IOC Auto-Detection
    - Paste any value into the home search bar and InCyter automatically
      identifies the type (MD5, SHA1, SHA256, SHA512, IP, Domain, URL,
      CVE, Email) and routes it to the correct scanner tab

  Home Dashboard
    - Time-based greeting (morning / afternoon / evening)
    - Live clock display
    - Quick-access cards for every enabled tab
    - Smart search bar with IOC auto-routing

  ATT&CK Badges (throughout the app)
    - Clickable technique badges appear in:
        CVE Lookup (CWE-inferred techniques)
        Adversary Intel (known actor TTPs)
        YARA Scanner results (rule-name-inferred techniques)
        Find Adversary inline panel (actor-inferred techniques)
        YARA inline panel on File & Hash tab
    - Each badge shows technique ID and tactic colour
    - Clicking navigates to the in-app ATT&CK Browser

  Direct DNS Resolution
    - All DNS lookups use Cloudflare 1.1.1.1 and Google 8.8.8.8 directly
    - Bypasses internal corporate DNS to avoid inaccurate results
    - Useful in restricted enterprise environments

  Drag & Drop
    - Drop files onto File & Hash tab for instant hash computation
    - Drop .eml or .msg files onto Email Analyser for instant parsing

  Clipboard Detection
    - Detects recognised IOC types on clipboard paste
    - Offers one-click auto-scan routing

  Multi-threaded Operations
    - All API calls run in background threads
    - UI remains responsive during long-running searches
    - Progress and status indicators throughout

  Session Caching
    - CISA KEV database loaded once per session
    - MISP Galaxy clusters cached per session
    - Reduces repeat API calls during an investigation

  Tooltip System
    - Hover tooltips on buttons, badges, and input fields
    - Explains what each control does without cluttering the UI

  Copy Buttons
    - Copy-to-clipboard buttons on hashes, IOCs, and result fields

  Offline Capability (partial)
    - PE Inspector: fully offline (no API required)
    - YARA Scanner: offline after rules are downloaded
    - Fuzzy Hash: fully offline
    - DMARC / SPF / DKIM parsing: uses direct DNS only (no third-party API)
